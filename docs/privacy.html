Privacy Policy

HerryVN is committed to protecting user privacy and securely handling cloud synchronization using Google Drive APIs.

Overview

This application allows users to synchronize and manage personal data using Google Drive cloud storage services.

Google Drive Access

The application requests permission to access the user's Google Drive in order to upload, sync, download, and manage files created or selected by the user inside the application.

These files may include:

  • Photos and images
  • Markdown documents
  • User-generated application content
  • Backup and synchronization data

Data Collection

We do not sell, transfer, or share user data with third parties.

User files remain stored within the user's own Google Drive account.

Authentication

Google Sign-In is used securely for authentication and permission management.

Data Deletion

Users may delete synchronized files directly from their Google Drive account or uninstall the application at any time.
