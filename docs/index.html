Privacy Policy

Last updated: May 2026

Overview

This application allows users to sync and manage their personal data using Google Drive.

Google Drive Access

The app requests access to the user's Google Drive in order to upload, sync, download, and manage user files created or selected within the application.

These files may include:

  • Photos
  • Markdown files
  • User-generated content
  • Application backup and sync data

Data Collection

We do not sell, share, or transfer user data to third parties.

User files remain stored in the user's own Google Drive account.

Authentication

Google Sign-In is used securely to authenticate users and grant access permissions.

Data Deletion

Users can delete their files directly from their Google Drive account or uninstall the application at any time.
